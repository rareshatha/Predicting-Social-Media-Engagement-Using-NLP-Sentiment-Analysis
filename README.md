# NLP Project – Predicting Social Media Engagement Using NLP and Sentiment Analysis

## 📄 Description

This project focuses on Natural Language Processing (NLP) workflows, involving:
- Importing and preprocessing textual data
- Conducting exploratory data analysis (EDA)
- Cleaning and preparing the dataset for modeling
- Applying Machine Learning and Deep Learning algorithms for text classification

The project is implemented in a Jupyter Notebook and follows a clear, step-by-step pipeline for data preparation and modeling.
